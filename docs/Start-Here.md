# เริ่มใช้งาน Hana

## 1. เพิ่ม Hana เข้าเซิร์ฟเวอร์

เจ้าของหรือผู้ดูแลเซิร์ฟเวอร์เพิ่ม Hana แล้วเปิดสิทธิ์พื้นฐานในห้องที่ต้องการใช้

- View Channel
- Send Messages
- Embed Links
- Use Application Commands
- Send Messages in Threads หากใช้ Thread

> หาก `/travelphoto` ขึ้นว่าไม่มีสิทธิ์ ให้ตรวจ `Embed Links` ของ Hana ในห้องหรือหมวดนั้นก่อน

## 2. ตั้งห้อง AI

ผู้ดูแลใช้ `/setroomai` ในห้องที่ต้องการให้สมาชิกคุยกับ Hana จากนั้นใช้ `/unsetroomai` เพื่อปิดได้ทุกเมื่อ

Hana จะตอบเฉพาะภาษาไทย อังกฤษ และญี่ปุ่น หากข้อความเป็นภาษาอื่น Hana จะไม่เดาความหมาย

## 3. เริ่มคุย

พิมพ์ข้อความในห้อง AI ได้ตามปกติ Hana จะอ่านบริบทการคุยล่าสุดของผู้พูดคนเดิมก่อนตอบ โดยไม่ปนกับสมาชิกคนอื่น

## 4. ตั้งค่าส่วนตัว

ใช้ `/settingai` เพื่อจัดการความจำ เวลา การแท็กตอบ ข้อมูลส่วนตัว และการอนุญาตให้ Hana ทักก่อน

## ใช้งานนอกเซิร์ฟเวอร์

คำสั่งต่อไปนี้เปิดให้ใช้ผ่าน User Install หรือ DM ได้:

- `/travelphoto`
- `/act`
- `/actwith`
- `/premium`

คำสั่งจัดการห้อง AI, ห้องเสียง และข้อมูลเซิร์ฟเวอร์ ใช้ได้เฉพาะในเซิร์ฟเวอร์
