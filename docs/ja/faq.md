# よくある質問

## Hana が返事をしません

RoomAI が有効か、Hana に View Channel と Send Messages があるか確認してください。メッセージはไทย語、英語、日本語である必要があります。

## なぜ答えずに質問を返すのですか？

曖昧なメッセージでは、Hana はまず直近の文脈を読みます。それでも意味が分からない時だけ、推測を避けるため短く確認します。

## なぜ写真を送ってくれないのですか？

場所が確認でき、Pexels から正しい結果を受け取れた場合のみ参考写真を送ります。他の場所の写真で代用しません。

## `/travelphoto` に Missing Permissions と出ます

管理者がそのチャンネルまたは Thread で Hana に `Embed Links` と `Send Messages` を許可してください。

## サーバーをまたいで記憶しますか？

初期設定では記憶しません。メモリーはサーバーごとに分かれ、`/settingai` で明示的に共有を許可した場合だけ共有されます。

## Hana が先に話しかけてくれません

スコアが 100 以上で、`/settingai` から許可をオンにする必要があります。

## 対応言語は？

ไทย語、英語、日本語のみです。
