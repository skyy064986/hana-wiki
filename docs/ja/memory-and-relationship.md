# メモリーと関係性

## メモリー

Hana のメモリーは初期設定で **Discord User ID + Server ID** ごとに分かれており、別のサーバーの会話が混ざりません。

`/settingai` で、このサーバーのメモリーのオン・オフ、メモリーの閲覧・削除、メモリー移動の確認、選択したメモリーのサーバー間共有を管理できます。

年齢、本名、国など、入力していない情報を Hana が推測することはありません。

## 関係性

関係性スコアもユーザーとサーバーごとに分かれています。礼儀正しく意味のある会話で少しずつ上がり、スパムでは上がりません。

圧力、境界線を越える行為、失礼な言葉、真剣な交際要求などで下がることがあります。Hana は丁寧に断り、友達としての境界線を保ちます。

## Hana から先に話しかける

100 点になると、`/settingai` で Hana から先にメンションすることを許可できます。

- 初期設定: オフ
- 1 日に最大 1 回
- 有効時、会話がない状態が 1〜3 日続くと話しかけることがあり、2 日目が中心
- 21 日より古いメモリーの話題を掘り返して挨拶しません
- `/settingai` からいつでもオフにできます
