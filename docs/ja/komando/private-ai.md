# Private AI

`/privateai` では、自分の Gemini API キーで個人用ロールプレイキャラクターを作成できます。Hana の人格、メモリー、キー、利用枠とは分離されています。キャラクターとメモリーは Discord User ID に紐づき、対応する RoomAI サーバーと DM で継続して利用できます。

## かんたん設定

1. `/privateai` を開き、Gemini Safety の注意事項に同意します。
2. **1 · キャラクター作成** で名前、経歴、性格、話し方を入力します。
3. **2 · Gemini キー追加** で API キーを 1 個以上入力します。まだキーがない場合は、[Gemini API キーの取得方法](../guides/get-gemini-api-key.md)をご覧ください。

キー確認後、利用可能なモデルを取得し、対応する Flash Lite を選んで Private AI を自動的に有効化します。プレイヤー名は事前設定せず、物語の中で自己紹介して関係を築けます。

## Gemini API キー

- 最大 10 個、一度に 5 欄まで追加できます。
- 最初の欄だけ必須です。もう一度開くと 6～10 個目を追加できます。
- 重複キーと無効なキーは別々に通知されます。
- キーは保存前に暗号化され、通常ログや Export には含まれません。

通常チャットにキーを投稿せず、必ず Panel から入力してください。専用キーを作成し、Google Cloud で上限を設定することを推奨します。

## 遊び方

| 形式 | 意味 |
| --- | --- |
| `通常の文章` | 文脈に沿った会話・描写 |
| `"文章"` | プレイヤーの台詞 |
| `*指示` | 台詞ではなく、物語外からのシーン演出指示 |
| `\文章` | AI を完全に回避し、キャラクターも Hana も応答しない |

```text
*舞台をカフェに移し、時間を午後まで進める
*一週間後まで Timeskip する
*雨を降らせ、建物を停電させる
*Yami の服を黒いドレスに変え、少し緊張させる
```

`*` 指示では、**詳細設定 → シーン** の日付、時刻、場所、キャラクターの服、プレイヤーの服、感情、出来事を更新できます。通常のロールプレイでも文脈に合わせて更新されます。待機中は入力中表示が出て、長い返答の各部分に `キャラクター名 •` が付きます。

## 詳細設定

- 外見、服装、関係性、世界観、境界線
- 返答の長さ、視点、詳細度、テンポ、動作表現
- 現在のシーン、直近の履歴、長期メモリー要約
- Gemini キーとモデルの選択、確認、削除
- キーを含まない Export、履歴消去、全データ削除

Gemini の Safety Filter により、成人向けの性的内容、暴力、その他のセンシティブな内容は拒否される場合があります。Hana はこの制限を回避しません。パスワード、住所、金融・健康情報、他人の秘密を入力しないでください。詳しくは[プライバシーと利用規約](../privacy-and-terms.md)をご覧ください。
