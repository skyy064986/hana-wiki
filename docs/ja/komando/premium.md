# Hana Premium

`/premium` で特典と Hana Discord への参加ボタンを確認できます。

Premium はサーバー単位の特典です。個人情報を自動的に追加収集するものではありません。

## 主な特典

- AI クォータの増加
- より多いメモリーとメモリー要約
- `/statusai` の詳細表示
- サーバー固有の情報やルールを追加する `/hanacontext`

## 購入・お問い合わせ

Premium の購入やお問い合わせは [Hana Discord](https://discord.gg/qWbQEABAPA) のみで受け付けています。
