# Hana を始める

## 1. サーバーに Hana を追加する

オーナーまたは管理者が Hana を追加し、使うチャンネルで次の権限を付与します。

- View Channel
- Send Messages
- Embed Links
- Use Application Commands
- Thread を使う場合は Send Messages in Threads

> `/travelphoto` で権限エラーが出る場合は、対象チャンネルまたはカテゴリで Hana の `Embed Links` を確認してください。

## 2. AI Room を設定する

管理者が使いたいチャンネルで `/setroomai` を実行します。停止はいつでも `/unsetroomai` でできます。

Hana が応答するのはไทย語、英語、日本語のみです。他の言語の意味を推測しません。

## 3. 会話を始める

AI Room で普通にメッセージを送ってください。Hana は回答前に同じ話者の直近の文脈を読み、他のメンバーの会話とは混ぜません。

## 4. 個人設定

`/settingai` でメモリー、タイムゾーン、返信時のメンション、個人プロフィール、Hana から先に話しかける許可を管理できます。

## サーバー外で使う

次のコマンドは User Install または DM でも使えます。

- `/travelphoto`
- `/act`
- `/actwith`
- `/premium`

AI Room、音声、サーバー管理コマンドはサーバー内のみで利用できます。
