# 更新履歴

## HanaBot v1.4.1 (beta) — 2026年9月28日

- `/privateai` は最大 5 スロットに対応しました。Gemini キー/モデルは共有し、シーン、メモリー、履歴、関係値は分離されます。
- キャラクター別の関係値、オン/オフ、交際・結婚提案、有効なスロットだけの本人用 `/profile` 表示を追加しました。
- `YES` 確認付きスロット削除、メモリー消去、キャラクターリセット、Gemini を保持する全リセットを追加しました。
- Private AI をローカル SQLite に移行し、API キー暗号化と最大 3 世代のローテーションバックアップに対応しました。
- シーン進行速度と話し方の説明を分かりやすくしました。
- 不要な通知を避けるため、Hana から先に話しかける機能を削除しました。
- 曖昧なメッセージを解釈する前に、Hana が前の文脈を読むようになりました。
- システム結果が未確認のまま写真送信・アクション完了を主張しないよう改善しました。
- `/travelphoto` と User Install/DM 対応を追加しました。
- `/act` または `/actwith` に `shrug`、`welcome`、`givegift`、`fistbump`、`dance` を追加しました。
- `/act` と `/actwith` は毎回新しい Anime GIF を取得します。

更新情報・お問い合わせは [Hana Discord](https://discord.gg/qWbQEABAPA) へどうぞ。
