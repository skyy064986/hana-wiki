# Hana へようこそ

Hana は自然に会話でき、日本の暮らしに合わせたステータスを持つ Discord App です。AI 機能と楽しいコマンドでサーバーを彩ります。

> Hana はไทย語、英語、日本語に対応しています。

## Hana にできること

| 分類 | 例 |
| --- | --- |
| AI Room | Hana と会話するチャンネルを設定し、設定に応じて会話を記憶 |
| Hana Life | 日本時間に基づく Hana の現在の行動や予定を確認 |
| Fun | Anime GIF、ミニゲーム、チャット内アクティビティ |
| Travel | 日本の都道府県に関する参考写真 |
| Server tools | Hana Context 用のサーバー情報とルール |
