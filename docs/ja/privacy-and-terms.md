# プライバシーと利用規約

## 入力しないでほしい情報

Hana に次の情報を送信・保存しないでください。

- 住所や正確な位置情報
- 電話番号、個人メール、パスワード
- カード情報や金融情報
- 身分証明書
- 健康情報や他人の機密情報

Hana に呼び名や簡単な文脈を伝えるには、ニックネーム、自主的に入力する年齢、一般的な大切な日付だけで十分です。

## Hana がしないこと

- 名前、プロフィール画像、言語から年齢や個人情報を推測すること
- システムが確認する前に写真を送った、行動を完了したと主張すること
- 恋愛ロールプレイを始めること。関係性は友達として保ちます

上記の友達関係の制限は Hana の人格に関するもので、`/privateai` でユーザーが作成したキャラクターには適用されません。ただし Private AI も Discord のルール、適用法令、Gemini Safety Filter に従います。

## Private AI と API キー

Gemini API キーは `/privateai` の専用フォームにだけ入力し、通常のチャットには投稿しないでください。キーは保存前に暗号化され、通常ログやデータ Export には含まれません。キャラクター情報、シーン、直近の履歴、メモリー要約は、同じ Discord User ID の対応サーバー/DM 間で共有されます。Panel から表示、消去、Export、全削除ができます。
