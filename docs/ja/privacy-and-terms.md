# プライバシーと利用規約

## 入力しないでほしい情報

Hana に次の情報を送信・保存しないでください。

- 住所や正確な位置情報
- 電話番号、個人メール、パスワード
- カード情報や金融情報
- 身分証明書
- 健康情報や他人の機密情報

Hana に呼び名や簡単な文脈を伝えるには、ニックネーム、自主的に入力する年齢、一般的な大切な日付だけで十分です。

## Hana がしないこと

- 名前、プロフィール画像、言語から年齢や個人情報を推測すること
- システムが確認する前に写真を送った、行動を完了したと主張すること
- 恋愛ロールプレイを始めること。関係性は友達として保ちます

上記の友達関係の制限は Hana の人格に関するもので、`/privateai` でユーザーが作成したキャラクターには適用されません。ただし Private AI も Discord のルール、適用法令、Gemini Safety Filter に従います。

## Private AI と API キー

Gemini API キーは `/privateai` の専用フォームにだけ入力し、通常チャットには投稿しないでください。キーは保存前に暗号化され、通常ログや Export には含まれません。最大 5 スロットでキー/モデルを共有し、キャラクター、シーン、メモリー、履歴、関係値は分離されます。データはボット端末内の SQLite に保存され、最大 3 世代のバックアップを持ちます。Panel から表示、消去、リセット、Export、削除ができます。アクティブデータを削除しても、ローテーションまたは管理者の消去までは古いバックアップに残る場合があります。
