# 日本の旅行写真

## `/travelphoto <prefecture>`

日本の都道府県を英語で選ぶと、Hana が Pexels からランダムな旅行参考写真を取得します。

```text
/travelphoto prefecture: Hokkaido
```

## 知っておくこと

- 写真は **Pexels の参考写真** であり、Hana 自身が撮影したものではありません。
- Hana は毎回新しく検索し、写真をキャッシュしません。
- 見つからない場合は同じ都道府県で再試行するか、別の都道府県を選んでください。
- サーバー、DM、User Install で使用できます。

## AI 会話中の写真

現在のステータスの旅行先または確認済みの旅行記録があり、写真を頼まれた場合、Hana は参考画像を送ろうとします。添付が実際に成功するまで「送った」とは言わず、別の都道府県の画像で代用しません。
