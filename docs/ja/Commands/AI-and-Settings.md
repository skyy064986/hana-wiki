# AI と設定

## `/statusai`

日本時間での Hana の現在の行動、時間帯、Discord ステータスを表示します。一部の詳細は Hana Premium の特典です。

## `/settingai`

他のメンバーには見えない、あなた専用の設定パネルです。

- 返信時のメンションをオン・オフ
- このサーバーでのメモリーをオン・オフ
- サーバー間共有を許可するメモリーを選択
- タイムゾーンを設定
- プロフィール情報を追加・編集・削除
- Hana から先に話しかけることを許可

> 住所、電話番号、パスワード、金融情報などの機密情報は入力しないでください。ニックネーム、自主的に入力する年齢、一般的な大切な日付で十分です。

### Hana から先に話しかける

初期設定はオフです。このサーバーで関係性スコアが 100 になると選べます。有効にすると、しばらく会話していない時に Hana がメンションすることがあります。繰り返し連投はせず、`/settingai` でいつでもオフにできます。

## `/profile`

入力したプロフィール情報と、このサーバーでの Hana との関係性を表示します。

| スコア | レベル |
| --- | --- |
| 0–24 | 知り合い |
| 25–100 | よく話す |
| 101–300 | 友達 |
| 301–500 | 親しい友達 |

Hana は友達として接し、自分から恋愛ロールプレイを始めません。

## `/hanainsights`

AI クォータと、このサーバーの権限を表示します。

## `/hanacontext` — 管理者向け

会話中に Hana が参照できるサーバー情報やルールを設定します。Premium 機能です。
