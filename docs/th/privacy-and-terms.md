# ความเป็นส่วนตัวและเงื่อนไข

## ข้อมูลที่ไม่ควรใส่

อย่าส่งหรือบันทึกข้อมูลต่อไปนี้ใน Hana:

- ที่อยู่หรือพิกัดละเอียด
- เบอร์โทร อีเมลส่วนตัว หรือรหัสผ่าน
- ข้อมูลบัตรหรือการเงิน
- เอกสารยืนยันตัวตน
- ข้อมูลสุขภาพหรือข้อมูลละเอียดอ่อนของผู้อื่น

หากต้องการให้ Hana เรียกชื่อหรือเข้าใจบริบทเล็กน้อย ใช้ชื่อเล่น อายุโดยสมัครใจ หรือวันสำคัญทั่วไปก็เพียงพอ

## สิ่งที่ Hana ไม่ทำ

- ไม่เดาอายุหรือข้อมูลส่วนตัวจากชื่อ รูปโปรไฟล์ หรือภาษา
- ไม่อ้างว่าได้ส่งรูปหรือทำ action แล้ว หากระบบยังไม่ยืนยันผล
- ไม่เริ่มบทโรแมนติก และรักษาความสัมพันธ์แบบเพื่อน

ข้อจำกัดความสัมพันธ์แบบเพื่อนข้างต้นเป็นบุคลิกของ Hana ไม่ใช่ตัวละครที่ผู้ใช้สร้างใน `/privateai` แต่ Private AI ยังต้องปฏิบัติตามกฎ Discord กฎหมาย และ Gemini Safety Filter

## Private AI และ API key

ใส่ Gemini API key ได้เฉพาะในแบบฟอร์ม `/privateai` ห้ามส่งในแชตปกติ ระบบเข้ารหัสคีย์ก่อนบันทึกและไม่นำคีย์ใส่ Log หรือไฟล์ Export สร้างได้สูงสุด 5 สล็อต โดยใช้คีย์/โมเดลร่วมกันแต่แยกตัวละคร ฉาก ความจำ ประวัติ และความสัมพันธ์ ข้อมูลเก็บใน SQLite ภายในเครื่องบอทและมี backup หมุนเวียนสูงสุด 3 ชุด คุณดู ล้าง รีเซ็ต Export หรือลบได้จาก Panel การลบข้อมูลที่กำลังใช้งานอาจยังไม่หายจาก backup เก่าทันทีจนกว่าจะหมุนเวียนหรือผู้ดูแลล้างสำเนา
