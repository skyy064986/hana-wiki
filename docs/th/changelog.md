# Changelog

## HanaBot v1.4.1 (beta) — 28 กันยายน 2026

- `/privateai` สร้างตัวละครโรลเพลย์ได้สูงสุด 5 สล็อต โดยใช้ Gemini key/โมเดลร่วมกัน แต่แยกฉาก ความจำ ประวัติ และความสัมพันธ์
- เพิ่มค่าความสัมพันธ์เฉพาะตัวละคร การเปิด/ปิดคะแนน การขอคบ/แต่งงาน และแสดงใน `/profile` เฉพาะสล็อตที่เปิดใช้งาน
- เพิ่มปุ่มลบสล็อตพร้อมยืนยัน `YES`, ลบความจำ, รีเซ็ตตัวละคร และรีเซ็ตทั้งหมดโดยเก็บ Gemini
- ย้าย Private AI ไปฐานข้อมูล SQLite ภายในเครื่อง พร้อมเข้ารหัส API key และ backup หมุนเวียนสูงสุด 3 ชุด
- ปรับชื่อและคำอธิบายความเร็วฉาก/วิธีพูดให้เข้าใจง่ายขึ้น
- ถอดระบบ Hana ทักก่อนออกทั้งหมด เพื่อลดการรบกวนสมาชิก
- ปรับ Hana ให้อ่านบริบทก่อนหน้าก่อนตีความข้อความกำกวม
- กันการอ้างว่าส่งรูปหรือแนบรูปโดยไม่มีผลลัพธ์จากระบบ
- เพิ่ม `/travelphoto` และการใช้งานผ่าน User Install/DM
- เพิ่ม `shrug`, `welcome`, `givegift`, `fistbump` และ `dance` ใน `/act` หรือ `/actwith` ตามประเภท
- `/act` และ `/actwith` ดึง Anime GIF ใหม่จากต้นทางทุกครั้ง

ดูข่าวสารและสอบถามข้อมูลอัปเดตได้ที่ [Hana Discord](https://discord.gg/qWbQEABAPA)
