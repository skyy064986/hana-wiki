# Private AI

`/privateai` ใช้สร้างตัวละครโรลเพลย์ส่วนตัวได้สูงสุด 5 สล็อตด้วย Gemini API key ของคุณ ระบบนี้แยกจากบุคลิก ความจำ คีย์ และโควตาของ Hana ข้อมูลผูกกับ Discord User ID เดียว จึงใช้ต่อกันได้ในห้อง RoomAI ของทุกเซิร์ฟเวอร์และ DM ที่รองรับ โดยไม่กระทบผู้ใช้คนอื่น

## เริ่มใช้งาน

1. เปิด `/privateai` และยอมรับคำเตือน Gemini Safety
2. กด **1 · สร้างตัวละคร** แล้วกรอกชื่อ ประวัติ นิสัย และวิธีพูด
3. กด **2 · เพิ่ม Gemini key** แล้วใส่ API key อย่างน้อยหนึ่งคีย์ หากยังไม่มีคีย์ ดู [วิธีรับ Gemini API key](../guides/get-gemini-api-key.md)

ระบบจะตรวจคีย์ ค้นหาโมเดลที่ใช้ได้ เลือก Flash Lite ที่รองรับ และเปิด Private AI ให้อัตโนมัติ ไม่ต้องกำหนดชื่อของคุณใน Panel ให้แนะนำตัวและค่อย ๆ สร้างความสัมพันธ์ในเรื่องได้เลย

## สล็อตตัวละคร

- สร้างได้สูงสุด 5 ตัว และเลือกตัวที่ต้องการคุยจากปุ่ม **สล็อตตัวละคร**
- Gemini key และโมเดลใช้ร่วมกันทุกสล็อต ไม่ต้องกรอกใหม่
- ตัวละคร ฉาก ความจำ ประวัติ และค่าความสัมพันธ์แยกจากกันทุกสล็อต
- ลบตัวละครได้โดยพิมพ์ `YES` เพื่อยืนยัน หากลบตัวสุดท้าย Private AI จะปิด แต่คีย์และโมเดลยังอยู่

## Gemini API key

- เพิ่มได้สูงสุด 10 คีย์ แบบฟอร์มแสดงครั้งละ 5 ช่อง
- ช่องแรกบังคับ ส่วนช่องอื่นเว้นว่างได้ เปิดอีกรอบเพื่อเพิ่มคีย์ 6–10
- ระบบแจ้งคีย์ซ้ำและคีย์ที่ตรวจไม่ผ่าน
- คีย์ถูกเข้ารหัสก่อนบันทึก ไม่แสดงใน Log และไม่รวมในไฟล์ Export

อย่าส่ง API key ในแชตปกติ ให้ใส่ผ่าน Panel เท่านั้น แนะนำให้สร้างคีย์แยกและตั้งโควตาใน Google Cloud

## วิธีเล่น

| รูปแบบ | ความหมาย |
| --- | --- |
| `ข้อความปกติ` | เล่าเหตุการณ์หรือคุยตามบริบท |
| `"ข้อความ"` | ระบุว่าเป็นคำพูดของผู้เล่น |
| `*คำสั่ง` | คำสั่งผู้กำกับจากนอกบท ไม่ใช่บทพูด |
| `\ข้อความ` | ข้าม AI ทั้งหมด ตัวละครและ Hana จะไม่ตอบ |

```text
*เปลี่ยนฉากไปคาเฟ่และเลื่อนเวลาไปตอนบ่าย
*Timeskip ไปอีกหนึ่งสัปดาห์
*ให้ฝนเริ่มตกและไฟดับในอาคาร
*เปลี่ยนชุดของ Yami เป็นเดรสสีดำและให้เธอรู้สึกประหม่า
```

คำสั่ง `*` เปลี่ยนวันที่ เวลา สถานที่ ชุดตัวละคร ชุดผู้เล่น อารมณ์ และเหตุการณ์ใน **การตั้งค่าขั้นสูง → ฉาก** ได้ การโรลปกติก็อัปเดตฉากตามบริบทได้เช่นกัน ระหว่างรอ Gemini จะมีสถานะกำลังพิมพ์ และคำตอบยาวจะถูกแบ่งพร้อม `ชื่อตัวละคร •` ทุกส่วน

## การตั้งค่าขั้นสูง

- รูปลักษณ์ ชุด ความสัมพันธ์ โลก และขอบเขตของตัวละคร
- ความยาว มุมมอง รายละเอียด จังหวะ และรูปแบบกิริยา
- ฉากปัจจุบัน ประวัติล่าสุด และสรุปความจำระยะยาว
- เลือก ทดสอบ หรือลบ Gemini key และโมเดล
- Export โดยไม่รวม API key ล้างประวัติ หรือลบข้อมูลทั้งหมด

## ค่าความสัมพันธ์ของตัวละครส่วนตัว

ค่าความสัมพันธ์เปิดเป็นค่าเริ่มต้นและคิดทุกข้อความที่ Gemini ตอบสำเร็จ โดยไม่ยิง API เพิ่ม:

| คะแนน | ระดับ |
| --- | --- |
| 0–50 | รู้จัก |
| 51–149 | เพื่อน |
| 150–249 | เพื่อนสนิท |
| 250 ขึ้นไป | คนคุย จนกว่าจะตกลงเป็นแฟน |
| ตกลงคบกัน | แฟน |
| ตกลงแต่งงาน | แต่งงาน |
| แต่งงานและถึง 2,000 | คู่ชีวิต |

ข้อความปกติได้ +1 สิ่งที่ตัวละครชอบได้ +2 ถึง +3 สิ่งที่ไม่ชอบไม่เพิ่ม และสิ่งที่เกลียดลด 1 ถึง 2 คะแนน คำสั่งผู้กำกับ `*` ข้อความซ้ำ และคำขอที่ API ตอบไม่สำเร็จจะไม่เพิ่มคะแนน ตัวละครอาจขอเป็นแฟนเมื่อถึง 500 และขอแต่งงานเมื่อเป็นแฟนและถึง 1,000 หากเปิด **ให้ตัวละครเป็นฝ่ายขอ** ผู้ใช้ปิดระบบคะแนนหรือปิดการขอได้ในแต่ละสล็อต เมื่อปิดคะแนนจะคงเดิมและไม่แสดงตัวละครนั้นใน `/profile`

## ล้างกับรีเซ็ตต่างกันอย่างไร

- **ลบความจำ**: ลบประวัติล่าสุดและสรุประยะยาว แต่คงตัวละคร ฉาก และความสัมพันธ์
- **รีเซ็ตตัวละครนี้**: รีเซ็ตฉาก การตั้งค่าโรล/ความจำ ประวัติ สรุป คะแนน สถานะ และคำขอของสล็อตนั้น แต่คงชื่อ/ข้อมูลตัวละครและสิ่งที่ชอบหรือไม่ชอบ
- **รีเซ็ตทั้งหมด (เก็บ Gemini)**: ลบทุกสล็อตและปิด Private AI แต่เก็บ API key กับโมเดล
- **ลบข้อมูลทั้งหมด**: ลบตัวละคร ความจำ ความสัมพันธ์ และ Gemini key ของผู้ใช้จากข้อมูลที่กำลังใช้งาน

ข้อมูล Private AI เก็บในฐานข้อมูล SQLite ภายในเครื่องบอทและมี backup หมุนเวียนสูงสุด 3 ชุด API key เข้ารหัสด้วย AES-256-GCM ก่อนบันทึก

Gemini มี Safety Filter เนื้อหา 18+ ความรุนแรง หรือเนื้อหาอ่อนไหวอาจถูกปฏิเสธ Hana จะไม่ช่วยข้ามตัวกรอง อย่าใส่รหัสผ่าน ที่อยู่ ข้อมูลการเงิน สุขภาพ หรือความลับของผู้อื่น ดูเพิ่มที่ [ความเป็นส่วนตัวและเงื่อนไข](../privacy-and-terms.md)
