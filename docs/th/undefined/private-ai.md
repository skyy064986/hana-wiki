# Private AI

`/privateai` ใช้สร้างตัวละครโรลเพลย์ส่วนตัวด้วย Gemini API key ของคุณ ระบบนี้แยกจากบุคลิก ความจำ คีย์ และโควตาของ Hana ตัวละครกับความจำผูกกับ Discord User ID เดียว จึงใช้ต่อกันได้ในห้อง RoomAI ของทุกเซิร์ฟเวอร์และ DM ที่รองรับ โดยไม่กระทบผู้ใช้คนอื่น

## เริ่มใช้งาน

1. เปิด `/privateai` และยอมรับคำเตือน Gemini Safety
2. กด **1 · สร้างตัวละคร** แล้วกรอกชื่อ ประวัติ นิสัย และวิธีพูด
3. กด **2 · เพิ่ม Gemini key** แล้วใส่ API key อย่างน้อยหนึ่งคีย์

ระบบจะตรวจคีย์ ค้นหาโมเดลที่ใช้ได้ เลือก Flash Lite ที่รองรับ และเปิด Private AI ให้อัตโนมัติ ไม่ต้องกำหนดชื่อของคุณใน Panel ให้แนะนำตัวและค่อย ๆ สร้างความสัมพันธ์ในเรื่องได้เลย

## Gemini API key

- เพิ่มได้สูงสุด 10 คีย์ แบบฟอร์มแสดงครั้งละ 5 ช่อง
- ช่องแรกบังคับ ส่วนช่องอื่นเว้นว่างได้ เปิดอีกรอบเพื่อเพิ่มคีย์ 6–10
- ระบบแจ้งคีย์ซ้ำและคีย์ที่ตรวจไม่ผ่าน
- คีย์ถูกเข้ารหัสก่อนบันทึก ไม่แสดงใน Log และไม่รวมในไฟล์ Export

อย่าส่ง API key ในแชตปกติ ให้ใส่ผ่าน Panel เท่านั้น แนะนำให้สร้างคีย์แยกและตั้งโควตาใน Google Cloud

## วิธีเล่น

| รูปแบบ | ความหมาย |
| --- | --- |
| `ข้อความปกติ` | เล่าเหตุการณ์หรือคุยตามบริบท |
| `"ข้อความ"` | ระบุว่าเป็นคำพูดของผู้เล่น |
| `*คำสั่ง` | คำสั่งผู้กำกับจากนอกบท ไม่ใช่บทพูด |
| `\ข้อความ` | ข้าม AI ทั้งหมด ตัวละครและ Hana จะไม่ตอบ |

```text
*เปลี่ยนฉากไปคาเฟ่และเลื่อนเวลาไปตอนบ่าย
*Timeskip ไปอีกหนึ่งสัปดาห์
*ให้ฝนเริ่มตกและไฟดับในอาคาร
*เปลี่ยนชุดของ Yami เป็นเดรสสีดำและให้เธอรู้สึกประหม่า
```

คำสั่ง `*` เปลี่ยนวันที่ เวลา สถานที่ ชุดตัวละคร ชุดผู้เล่น อารมณ์ และเหตุการณ์ใน **การตั้งค่าขั้นสูง → ฉาก** ได้ การโรลปกติก็อัปเดตฉากตามบริบทได้เช่นกัน ระหว่างรอ Gemini จะมีสถานะกำลังพิมพ์ และคำตอบยาวจะถูกแบ่งพร้อม `ชื่อตัวละคร •` ทุกส่วน

## การตั้งค่าขั้นสูง

- รูปลักษณ์ ชุด ความสัมพันธ์ โลก และขอบเขตของตัวละคร
- ความยาว มุมมอง รายละเอียด จังหวะ และรูปแบบกิริยา
- ฉากปัจจุบัน ประวัติล่าสุด และสรุปความจำระยะยาว
- เลือก ทดสอบ หรือลบ Gemini key และโมเดล
- Export โดยไม่รวม API key ล้างประวัติ หรือลบข้อมูลทั้งหมด

Gemini มี Safety Filter เนื้อหา 18+ ความรุนแรง หรือเนื้อหาอ่อนไหวอาจถูกปฏิเสธ Hana จะไม่ช่วยข้ามตัวกรอง อย่าใส่รหัสผ่าน ที่อยู่ ข้อมูลการเงิน สุขภาพ หรือความลับของผู้อื่น ดูเพิ่มที่ [ความเป็นส่วนตัวและเงื่อนไข](../privacy-and-terms.md)
