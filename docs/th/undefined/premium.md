# Hana Premium

ใช้ `/premium` เพื่อดูสิทธิประโยชน์และปุ่มเข้า Hana Discord

Premium เป็นสิทธิ์ระดับเซิร์ฟเวอร์ ไม่ใช่การเก็บข้อมูลส่วนตัวเพิ่มโดยอัตโนมัติ

## สิทธิ์หลัก

- โควตา AI สูงขึ้น
- ความจำและสรุปความจำมากขึ้น
- รายละเอียด `/statusai` เพิ่มขึ้น
- ใช้ `/hanacontext` เพื่อเพิ่มข้อมูลและกฎเฉพาะเซิร์ฟเวอร์

## ติดต่อหรือสอบถาม

ซื้อ Premium หรือสอบถามรายละเอียดได้ที่ [Hana Discord](https://discord.gg/qWbQEABAPA) เท่านั้น
