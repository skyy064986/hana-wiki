# ความสนุกและ Anime GIF

## `/act <action>`

ส่ง Anime GIF สำหรับการกระทำของตัวเอง

ตัวอย่างท่าคนเดียว:

- `dance`
- `wave`
- `clap`
- `laugh`
- `shrug`
- `cry`, `happy`, `blush` และท่าอื่นตามรายการที่ Discord แสดง

## `/actwith <action> <user>`

ส่ง Anime GIF ทำกิจกรรมกับผู้ใช้อื่น เลือกว่าจะแท็กผู้รับหรือไม่ก็ได้

ตัวอย่าง:

- `dance`
- `fistbump`
- `welcome`
- `highfive`
- `hug`, `cuddle`, `kiss`

ท่าที่ใกล้ชิดจะให้ผู้รับกดยอมรับก่อน Hana จึงส่ง GIF

### `givegift`

ใช้ `/actwith givegift` เพื่อให้ของขวัญแก่คนอื่น

1. เลือกผู้รับ
2. เขียนข้อความของขวัญได้ตามต้องการ
3. เพิ่มลิงก์ของขวัญแบบ `https://` ได้ แต่ไม่บังคับ
4. ตรวจตัวอย่างและกดส่งยืนยันอีกครั้ง

> **คิดก่อนส่ง:** ข้อความและลิงก์ถูกโพสต์ในห้อง คนอื่นที่มองเห็นห้องอาจกดลิงก์หรือรับของก่อนผู้รับได้ อย่าส่งลิงก์ส่วนตัว รหัส หรือสิ่งที่ไม่ควรเปิดเผย

## `/hanagame`

เปิดมินิเกมของ Hana ในแชต เลือกเกมจาก Panel ที่ระบบแสดง

มินิเกมจะพยายามใช้โจทย์ local ก่อน เพื่อลดเวลารอและไม่ใช้ AI โดยไม่จำเป็น

## ความเร็วและ GIF ซ้ำ

Hana เรียก Anime GIF ใหม่จากต้นทางทุกครั้ง ไม่เก็บ cache ของ `/act` และ `/actwith` ไว้ในบอท

อย่างไรก็ตาม ผู้ให้บริการ GIF อาจสุ่มรูปเดิมกลับมาได้บ้างตามข้อมูลของต้นทาง
