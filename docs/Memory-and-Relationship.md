# ความจำและความสัมพันธ์

## ความจำ

ความจำของ Hana แยกตาม **Discord User ID + Server ID** เป็นค่าเริ่มต้น จึงไม่เอาเรื่องจากเซิร์ฟเวอร์หนึ่งไปปนกับอีกเซิร์ฟเวอร์

คุณควบคุมได้จาก `/settingai`:

- เปิดหรือปิดความจำในเซิร์ฟเวอร์ปัจจุบัน
- ดูหรือลบความจำ
- ย้ายความทรงจำเมื่อระบบให้ยืนยัน
- เปิดแชร์เฉพาะความจำที่คุณอนุญาตข้ามเซิร์ฟเวอร์

Hana ไม่ควรเดาข้อมูลที่คุณไม่ได้กรอกเอง เช่น อายุ ชื่อจริง หรือประเทศ

## ความสัมพันธ์

คะแนนความสัมพันธ์แยกตามผู้ใช้และเซิร์ฟเวอร์เช่นเดียวกับความจำ

คะแนนเพิ่มช้า ๆ จากการคุยอย่างสุภาพ ต่อบทสนทนา สนใจสิ่งที่ Hana ชอบ หรือจำรายละเอียดเล็ก ๆ ได้ ไม่เพิ่มจากการสแปม

คะแนนอาจลดจากการกดดัน ล้ำเส้น หยาบคาย หรือขอคบ/จีบอย่างจริงจัง Hana จะปฏิเสธอย่างสุภาพและรักษาขอบเขตความเป็นเพื่อน

## Hana ทักก่อน

เมื่อคะแนนถึง 100 คุณเลือกเปิดสิทธิ์ให้ Hana แท็กทักก่อนได้จาก `/settingai`

- ค่าเริ่มต้น: ปิด
- ทักได้ไม่เกินวันละครั้ง
- หากเปิด Hana อาจทักหลังหายจากการคุย 1–3 วัน โดยมักเป็นวันที่ 2
- หัวข้อความจำเกิน 21 วันจะไม่ถูกนำมาขุดชวนคุย
- ปิดได้ทุกเมื่อจาก `/settingai`
