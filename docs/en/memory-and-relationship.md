# Memory and relationship

## Memory

By default, Hana's memory is separated by **Discord User ID + Server ID**, so a conversation from one server does not mix into another.

In `/settingai`, you can turn memory on or off for the current server, view or delete memory, confirm a memory transfer, and approve selected cross-server sharing.

Hana must not guess details you did not provide, including your age, real name, or country.

## Relationship

Relationship score is also separated by user and server. It grows slowly from respectful, meaningful conversation and does not grow from spam.

The score can fall for pressure, boundary crossing, rudeness, or serious romantic requests. Hana declines politely and keeps a friendship boundary.

Hana does not use memory to send unsolicited proactive tags. That feature was removed to avoid disturbing members.
