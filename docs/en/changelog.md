# Changelog

## HanaBot v1.4.1 (beta) — 28 September 2026

- `/privateai` now supports up to five character slots sharing Gemini keys/model while keeping scene, memory, history, and relationships isolated.
- Added per-character relationship scoring, toggles, dating/marriage proposals, and owner-only `/profile` display for enabled slots.
- Added `YES`-confirmed slot deletion, clear memory, reset character, and reset-all-while-keeping-Gemini controls.
- Migrated Private AI to local SQLite with encrypted API keys and up to three rotating backups.
- Clarified scene pacing and speaking-style controls.
- Removed Hana's proactive greeting/tag system to avoid disturbing members.
- Hana now reads earlier context before interpreting ambiguous messages.
- Prevented claims that a photo or action was sent without a confirmed system result.
- Added `/travelphoto` and User Install/DM support.
- Added `shrug`, `welcome`, `givegift`, `fistbump`, and `dance` in `/act` or `/actwith` where applicable.
- `/act` and `/actwith` fetch a fresh Anime GIF every time.

For updates or questions, visit [Hana Discord](https://discord.gg/qWbQEABAPA).
