# AI and settings

## `/statusai`

Shows Hana's current Japan-time activity, part of the day, and Discord status. Some details require Hana Premium.

## `/settingai`

Your personal control panel; other members cannot see it.

- Turn reply mentions on or off
- Turn memory on or off for this server
- Choose memory you approve for cross-server sharing
- Set your timezone
- Add, edit, or delete personal profile details
- Allow Hana to message you first

> Do not enter your address, phone number, password, financial details, or other sensitive data. A nickname, voluntary age, or a basic important date is enough.

### Hana messages first

This is off by default and becomes available at a relationship score of 100 in that server. When enabled, Hana may tag you after some time apart, never repeatedly. Turn it off any time in `/settingai`.

## `/profile`

Shows the profile details you entered and your relationship level in this server.

| Score | Level |
| --- | --- |
| 0–24 | Acquaintance |
| 25–100 | Regular chat |
| 101–300 | Friend |
| 301–500 | Close friend |

Hana is a friend only and never begins romantic roleplay.

## `/hanainsights`

Shows AI quota and this server's entitlements.

## `/hanacontext` — Administrators

Set server information or rules that Hana can reference while chatting. This is a Premium feature.
