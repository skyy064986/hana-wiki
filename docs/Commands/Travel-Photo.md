# รูปท่องเที่ยวญี่ปุ่น

## `/travelphoto <prefecture>`

เลือกจังหวัดในญี่ปุ่นเป็นภาษาอังกฤษ แล้ว Hana จะสุ่มรูปอ้างอิงการท่องเที่ยวจาก Pexels

ตัวอย่าง:

```text
/travelphoto prefecture: Hokkaido
```

## สิ่งที่ควรรู้

- รูปเป็น **ภาพอ้างอิงจาก Pexels** ไม่ใช่รูปที่ Hana ถ่ายเอง
- Hana ค้นรูปใหม่ทุกครั้ง จึงไม่ตั้งใจเก็บ cache รูปเดิม
- หาก Pexels หาไม่เจอ ให้ลองจังหวัดเดิมอีกครั้งหรือเลือกจังหวัดอื่น
- ใช้ได้ทั้งในเซิร์ฟเวอร์และ DM/User Install

## รูปจากบทสนทนา AI

เมื่อ Hana มีสถานที่ท่องเที่ยวในสถานะปัจจุบันหรือบันทึกทริปที่ยืนยันได้ และผู้ใช้ขอดูรูป ระบบจะพยายามส่งรูปอ้างอิงให้

Hana จะไม่พูดว่าส่งรูปแล้วหากระบบยังไม่ได้แนบรูปสำเร็จจริง และจะไม่ใช้รูปจากจังหวัดอื่นมาแทนเพื่อกันข้อมูลผิด
